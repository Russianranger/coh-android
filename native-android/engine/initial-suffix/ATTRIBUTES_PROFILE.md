# Additive source-ordered full-attribute suffix profile

`coh_initial_suffix_attributes_diagnostic` keeps the original suffix API, original
stage-byte function and all existing monitor/social implementations unchanged.
Nine nonattribute dispatcher stage bodies are byte-identical to the frozen
qualified suffix. The additional profile replaces only the attribute loan and
reader with the schema-bound full/monitor transaction. Character/PowerInfo/
modes/badges/inventory/social/dynamic/sky/slave still consume the same qualified
native children in their original order, with one scratch loan alive at a time.

The new profile names the exact immutable parsed schema, expected cache SHA,
cache lease and optional cancellation provider. Their complete metadata/cache/
context/scratch spans are validated for aliases and charged before any callback
or allocation. Parent/child subtraction removes only bytes/reserve explicitly
charged again by the full child. The packet input is charged once per sequential
child, not removed from a parent subtotal that excludes it. All enclosing spans
are checked against provider loans, including profile, schema/cache and control
objects. Providers receive the preallocation maximum, and populated partial
error loans release once. Named8MiB and stricter4MiB child gates remain; the full
attribute child additionally obeys its existing2MiB bound. External callback/
zlib/crypto stack and sanitizer closure are not inferred.

Public reader/output always remain unchanged. A complete raw diagnostic still
returns UNSUPPORTED for unowned dynamic/world/dictionary generation, with all
actor, full-update and ACK flags false. Active invention and impossible initial
social flags retain their original refusal. Caller must keep packet/profile/
schema identity immutable under the declared leases while using/replaying the
packet-backed diagnostic; counts are not substitute dictionary authority.

Qualification reuses the exact successful retained suffix bytes and frozen
whole-original full-attribute corpus. It joins80 full profiles at matching source
bit offsets, preserving the original character/global prefixes. Only empty
scalar dynamic/sky/slave leaves are relocated after the new attribute body;
compressed byte arrays are never moved across an unqualified alignment boundary.
The old55 source profiles exercise this new profile (40 supported monitor/no-
attribute cases,15 precise refusals), rather than replaying original producers
or rerunning the old CI suite. Exact full spans/counts, sequential cleanup,
late callback cancellation, child acquisition failures, partial loans, parent
aliases, manifest mismatch and budget refusal are tested independently.

These are explicit synthetic source-leaf compositions. They do not execute a
whole original live entity graph, observe the current server cache branch,
perform original attribute application, qualify an Android application, or
permit actor publication/READY/RECEIVED_CHARACTER/application ACK.

Attribute-stage allocation receives at most the standalone 2 MiB aggregate allowance minus all retained parent/context/cache/input charges, before the provider allocates. A targeted oversized-provider refusal checks this allowance and preserves reader/output with all earlier loans released.
