# Gameplay HUD provenance and compatibility

Recovered source root: coordinator `upstream/ouroboros`. `source-hashes.json` records 11 exact original source files. Production code is additive portable C99; temporary source oracles compile original bodies without embedding them in the shipping module.

| Source | Audited behavior | Implemented and qualified scope |
|---|---|---|
| `Game/src/UI/uiStatus.c` | Health + max absorb divided by max health + absorb; separate absorb bar. Health color thresholds .2/.4/.6; endurance .3/.7; original colors and phase gray | Bounded finite snapshot ratios and two bars, separate absorb; actual original color functions plus original interpolation are compiled and compared 30,759 times. Healing pulses, rage, XP and notification behavior are pending. |
| `Game/src/UI/sprite/sprite_base.c` | Byte channel interpolation uses truncated unsigned deltas; logical UI scaling and atlas draw submission | New color helper exactly matches compiled original interpolation. Existing qualified `coh_ui` scaling/clip/drawlist is reused unchanged. New final-pass GLES has independent pixel tests, no original full-scene renderer parity claim. |
| `Common/gameComm/trayCommon.h`, `Game/src/UI/uiTray.c` | Primary tray is 10×1; power icon resource lookup; local slot/UI selection separated from later actions | Ten bounded slots, icon callback IDs, readiness/recharge values and copied power intent. Original recharge swirl, dragging, targeting/game actions are not implemented. |
| `Game/src/UI/uiTarget.c` | Target display reads entity name/health and phase/status from game state | Copied actor/target IDs, target label/bar and local target intent. No entity pointers, replication or combat policy. |
| `Game/src/UI/uiChat.c` | Chat windows/history/entry are separate UI data, with focus/edit paths and channel formatting | Eight copied message lines and single-line UTF-8 input with local submit intent. Rich formatting/channel routing and network delivery remain out of scope. |
| `Game/src/UI/uiLogin.c` | Character-selection UI drives selection/action, while server/login logic has independent ownership | Bounded character menu and copied character IDs/intents. No protocol/auth modifications or claims. |
| `Game/src/UI/uiFocus.c` | Single editable focus owner | Unchanged previously qualified `coh_ui` focus. New modal HUD state disables other focusable gameplay controls; touch/controller and scalar backspace are regression tested. |
| `Game/src/UI/sprite/sprite_font.c` | `ttMontBold=ttFontLoadCached("mont_hvbold.ttf",1)`, then `TTGGM_NOHINT`; `gameBoldFont` uses it as a fallback face | Generator reads actual original Montreal Heavy asset, uses FT_LOAD_NO_HINTING and normal grayscale. This establishes an authentic game-bold face, not the complete original composite font selection. |
| `Game/src/graphics/truetype/ttFontCore.c` | Per-character FreeType lookup, default pixel size, transform render/default size, NOHINT flag and normal grayscale render | Atlas default render size equals design size, so transform identity; same load/raster mode. FreeType 2.13.2 host differs from legacy version. Independent fontTools hmtx advances match within 1/64px. Original anti-aliasing/shadow/kerning/composite fallback GPU parity is pending. |
| `Game/src/graphics/ttFont.c` | File-based composite font caches/fallback | Public immutable sorted glyph atlas, source resource IDs and caller ownership. Decode/raster/upload happens outside the playback/frame path. No Win32 font loading is retained. |

Original fonts came from the existing external `coh-assets-v1.0.0` pack, not an arbitrary replacement font. `font-provenance.json` records release URL, stable ETag, per-entry CRC and new SHA identities. The coordinator recovered bounded ranges and validated the inner entries; the full outer archive was not hashed locally, and that limitation is explicit. Montreal Heavy SHA256 is `714351827092d0ed290a8625a75780636b66c66fcc91d575bb80a633ae0c4329`. Source font and derived atlas are supplied at packaging time, preserving the existing external asset-pack identity. No new redistribution-rights assumption is made.
