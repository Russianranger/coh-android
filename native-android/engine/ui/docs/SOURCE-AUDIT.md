# Gate 34 source audit

Original source was recovered read-only by the coordinator under `upstream/ouroboros` at the shared checkout. Reference paths are from `Russianranger/coh-android`; `source-hashes.json` pins exact bytes independently of the outer worktree HEAD. These sources are already part of the project's existing source corpus. No new game asset or font license/distribution assumption is introduced by this module.

| Original file | Observed behavior | Framework disposition |
|---|---|---|
| `Game/src/UI/sprite/sprite_base.h` | `DEFAULT_SCRN_WD=1024`, `DEFAULT_SCRN_HT=768`; sprite scaling/position modes; atlas/basic texture quads, UVs and clipper inputs | 1024×768 logical plane, explicit XY/none/centered-fit subset, clipped generic image/glyph quads. Remaining individual-axis options are not claimed. |
| `Game/src/UI/sprite/sprite_base.c`, `calc_scrn_scaling_with_offset` | Default width/1024 and height/768; letterbox picks the smaller ratio and centers the other axis; fixed-pixel/runtime branch can force both scales to one | Exact original body is compiled by the oracle with shell mode selected, then compared for 256 resolutions × 3 modes. Adapter explicitly chooses a scale mode. |
| same file, `point_cbox_clsn` | Inclusive CBox edges and explicit `(x != 0 && y != 0)` mouse restriction | Inclusive edges preserved, zero-coordinate exclusion intentionally omitted for Android touch. Rectangles reject nonfinite/negative sizes instead of normalizing ambiguous invalid input. |
| `Game/src/UI/uiFocus.c` | One focus owner, editable bit, returning focus, optional lost-focus veto callback | Exact full original body is compiled and compared for 259 transitions between no focus, two buttons and editable input. Veto callbacks remain unsupported; no source parity claim for that branch. |
| `Game/src/UI/uiBox.c` | Explicit rectangle conversion, intersection, edge enclosure and input helpers | Positive-size rectangles, ancestral clip intersection and bounded hit testing. Original dynamic memory pool is not reused; caller arena replaces ownership. |
| `Game/src/UI/uiWindows.c` | Saved window dimensions/scale, window/child decorations using atlas sprites, dynamic small font at low scale, text and child spacing | Anchored window/container widgets and explicit font/resource IDs. Curved/decorated/drag windows, saved window persistence and font-selection policy are pending. |
| `Game/src/UI/uiEditText.c` | Existing formatted text, cursor positions and edit behavior depend on old UI and platform input | UTF-8 committed single-line text and scalar backspace only. Rich text/cursor selection/composition are explicitly pending. No full editor parity claim. |
| `Game/src/graphics/truetype/ttFontCore.c`, `ttFontLoad`, `ttFontLoadCachedFace` | FreeType font face opens through file streams; cached face selection; Windows critical sections around face loading | Reusable atlas-glyph callback is a deliberate integration boundary. Original rasterization/cache code is not executed. Game font/assets, metrics, fallback, shaping and GL upload need independent qualification. |

The module is newly written portable C99; the production runtime does not embed extracted original platform code. Original source bodies appear only in temporary oracle translation units at test time. Mock glyphs used in unit tests are intentionally synthetic metrics/UVs and do not prove authentic CoH font appearance. Complete original UI visual parity is not claimed.
