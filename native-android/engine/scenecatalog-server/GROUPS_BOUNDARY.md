# Private same-boundary caller preparation

`stage_groups_boundary.py` accepts only the pinned original groupnetsend.c and
prepares a private translation unit with original producer code plus additive
supplier/owner/transaction helpers. It installs no callbacks and writes no source
file. The default transaction hooks stay zero. No startup hook, service, workflow,
server run, filesystem sink or receive observation is installed by this work.
The original guarded anim.c quiet implementation must separately be linked.

A future original main owner-thread caller may prepare a hook value with
`coh_groups_boundary_prepare`, then explicitly install it only after satisfying
all scheduling and owned output prerequisites. Preparation alone does not observe
anything. It cannot accept source hashes, DBID, world generation or detached
catalog bytes in place of actual source objects.

For a full update the callbacks acquire the real try-only model/LOD quiet lease,
observe actual registered link/client/entity ownership, then export a fresh
complete catalog, root/future snapshot and resource rows. The same lease remains
held through PRE-producer eligibility and exact original logical packet output.
Packet output is provisional; commit follows successful actual quiet release.
Any callback/export/owner/packet refusal aborts all provisional outputs. A failed
quiet release quarantines this helper from another observation; it does not
pretend the source locks were released. The original packet send still executes
normally, whether diagnostic capture succeeds or fails.

IDs increment locally without wrap and merely associate the fresh supplier
outputs and eligibility in this process. They are not source/runtime/session
capabilities. The sink must independently bind actual owned run/source receipts
and all exact output hashes, including packet bit extent, alignment, compression
and selected source owner identity. Kind1 is the fixed COHOWN01 owner record;
kind2 COHCAT, kind3 COHRTS, kind4 COHRES and kind5 fixed eligibility records.
All writes are provisional and synchronously copied. Packet bytes include the
original command and preserve final-byte bit extent, never guessed normalization.

Original worldSendUpdate changes last_world_id, last_update_time and file
force_reload. Owner comparison excludes only the first two owner-record words;
all other owner bytes must remain equal. The saved/force flags captured by the
eligibility hook remain the actual pre-state, rather than the modified post-state.
Source group/catalog objects are valid and exclusive for the whole call; no
callbacks may yield, load, mutate source, recurse, or serialize other properties.
The static record scratch is128KiB; total emitted data is capped128MiB, with the
existing per-export caps retained. These are output/scratch limits, not a hard
bound on original packet allocator growth or sink/provider live allocations.

Missing installation prerequisites remain concrete: fully returned original
background-loader initialization, exclusive original group/link/entity/model/
library/trick thread scheduling, disabled folder callbacks/manual callback mode,
no new lazy loads through the original producer's transitive services, owned
private sink/run receipt and source identity chain, transport normalization and
actual native opaque-owner receive evidence. The quiet guard only protects the
original GEO/LOD queues, not arbitrary group/entity or folder mutations. These
preconditions cannot be supplied as fabricated booleans. A real source caller
and sink must be independently reviewed before any new capture.

Host tests use explicitly substituted quiet/export/owner dependencies to qualify
caller orchestration, rollback and bounds, plus the unchanged original
worldSendUpdate and packet serializer fixture where noted. Fixture lease success
is never evidence of original runtime quiescence. There is no Win32 build,
Android execution, actual server capture, crypto/actor/CLIENT material/LOD or
world-authority qualification from this preparation.
