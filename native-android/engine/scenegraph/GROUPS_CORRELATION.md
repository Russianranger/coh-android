# Normal GROUPS source compatibility

`coh_runtime_graph_compare_groups` is an allocation-free synchronous comparison between an observed normal-world body, an immutable complete source graph, and the catalog owner whose actual retained bytes the graph borrows. It accepts byte-aligned new-world bodies only. It compares original file ordering, exact file names/bounds checksums, every transmitted definition serialization, every root slot/name/packed matrix serialization, map-file path and the complete footer. File0 must transmit every retained allocated record. The graph, owner and source inputs remain immutable and pinned throughout the call. No ownership is acquired implicitly.

The graph already qualified the packed matrix bytes against observed raw source root matrices. Matching packed wire therefore correlates the observed wire to that source snapshot using its existing pack/unpack qualification; it does not claim new bit-exact native trigonometry or infer another raw transform. Every live wire byte and graph input stays borrowed. Known input/control/output overlap is rejected before writes; opaque ownership allocation/control disjointness remains a caller obligation. Report publication happens only after all checks succeed. The reader is never advanced. Named graph/owner/snapshot/wire storage, a64KiB stack reserve and output are charged with checked arithmetic under96MiB; all other retained resources belong in caller retained_bytes. There is no per-world eager materialization or allocation.

## Original omission and import rules

Pinned `MapServer/src/group/groupnetsend.c` SHA256 `cd739e2a1b424bf089017be73d3c42adef0f23aca7563e8577cfc98ecdfebff9` establishes:

- `sendGroupFile` omits unchanged files for incremental delivery unless force_reload. For a present normal file it sends fullname and bounds_checksum before definition changes.
- Even full_update skips nonzero-file definitions when saved and the file is unmodified, unless force_reload. File0 has file_idx0 and does not meet this saved-definition omission predicate. Incremental mod_time filtering is separate.
- `worldSendUpdate` sends file slots1..N-1 then0, followed by root slots, a sentinel and file count/active-root count/definition CRC/reference CRC. Full updates send every allocated root tracker slot, including inactive root names.

Pinned `Game/src/group/groupnetrecv.c` SHA256 `f4cccb5a51acea3448191965470eaa349034c4f6fa1c729fa52aed0888c7004d` establishes:

- `receiveGroupFile` imports an absent local named bounds file by checksum, falling back to full source load, before applying transmitted definition changes.
- Root names resolve against loaded definitions; missing definitions trigger original out-of-sync handling. Root transforms are consumed through getMat4. Footer counts/CRCs are distinct from identity or resource admission.

This comparator retains every imported catalog definition, including wire omissions, holes and tombstones; it does not delete omitted references. Catalog bytes do not retain saved/modified_on_disk/force_reload flags. Consequently the comparator cannot certify the eligibility of every nonzero-file omission. It provides strict observed-wire compatibility with the complete imported source graph, not a proof that a captured catalog belongs to this live server generation. Another live scene may legitimately differ and is refused; delta application needs a separate qualified transaction.

## Visitor and qualification boundaries

The additive `coh_rep_groups_visit` runs a complete structural preflight before invoking any callback, then exposes exact source-order borrowed file-header, full definition and root spans in a second bounded walk. Each event expires when its callback returns. Callbacks must stage externally and discard on any failure; successful callbacks never grant publication. Malformed/unsupported preflight input invokes no callback. Default `coh_rep_groups` behavior and allocation policy remain unchanged.

## Scripted UDP observer composition

`check_runtime_groups_udp.py` composes the frozen mapclient observed-service seam with this comparator over actual OS UDP. A qualified original fixture7 catalog/runtime graph is retained with an explicit catalog-owner lease and snapshot allocation until graph retirement. The envelope is synthetic, with unchanged original definition/matrix bytes and32 legal deterministic loadscreen page names; its16,871-byte body intentionally crosses the owned decoded-message boundary. The scripted peer compresses using the existing source packet format and sends real fragment datagrams. Service runs after each fragment: no observer runs early. The synchronous callback verifies exact body bytes, post-normalized-command cursor32, actual selected slot/DBID/selection generation/map link/map generation and provisional development flag before invoking the bounded comparator.

602 controls and three scenarios pass in each of release, ASan and UBSan: matching immutable owner/graph compatibility; a byte-equal different owner refusing without changing output; and a late extra body byte preventing every callback. The owned network loan exists during the callback and is released on all paths. The observer is not retained or replayed. SCENE_INCOMPLETE remains, no application ACK/READY/character publication occurs, and transport-only ACKs are drained and checked. Owned sockets, pending packets and process file-descriptor counts return to their starting boundaries. The test uses a conservative32MiB caller reservation for other live test/network resources; this is no whole-process memory measurement. It does not start a MapServer, receive the accepted Thor body, authenticate an account or admit a source/resource/world generation.
