# Observed model bounds and disk source fields

`coh_model_bounds` reads borrowed, immutable, already admitted uncompressed GEO headers in original disk-row order. It supports original versions 0, 2, 3, 4, 5, 7 and 8; version 6 remains refused. Fixed 216-byte old records and bounded variable records retain their exact source fields. The numerical view contains min, max, scale and radius. Names, records and headers remain borrowed; their owner must outlive every view and cursor. No heap, file access or callback occurs in the adapter.

Original `Common/seq/anim.c:readModel` directly copies these fields. `geoLoadStubs` subsequently binds names/owners, initializes trick nodes and sorts model pointers; it does not normalize these fields. `modelInitTrickNodeFromName` changes the trick node, rather than these numerical fields. The host oracle extracts those unchanged original functions and uses explicit original disk-layout shells; this is source qualification, not Win32 ABI execution. Separate sequencer paths can change a model radius, so these observations do not establish an invariant that all model instances remain unchanged forever.

The comparator checks all ten float bit patterns exactly, including signed zero. It neither multiplies model scale into the box nor applies a generic normalization rule. Original group bounds copy model min/max directly; later transformed group bounds and CLIENT trick/LOD decisions remain separate contracts. Finite ordered bounds and nonnegative radius are required; finite negative scale is preserved.

The parser caps the header at 32 MiB and 65,536 rows, uses checked extents and linear row cursors, rejects known source/control/output overlap before writes, and publishes outputs only on success. Caller-created table/cursor metadata must originate from these APIs and remain immutable except through `next`. Header ownership, immutable bytes and disjoint opaque surrounding allocations remain caller obligations.

## Qualification

`check_model_bounds.py` passed 5,749 controls and 126 unchanged-original copy/trick checks in each of release, ASan and UBSan. Controls cover all seven admitted versions, every-byte truncation, malformed numeric/name/extent inputs, mismatch bits, aliases and unchanged outputs/cursor on refusal. These checks execute on the host; Android and physical qualification are absent.

`inspect_model_bounds.py` reused the retained run 38994607354 catalog/runtime/resource triple and all 391 independently acquired candidate bodies. It first delegates complete body/core/header/model/partition checking to the source resource index, then walks each selected file once using the exact admitted original disk row. All 8,250 captured source-owner observations matched disk min/max/scale/radius in all three modes. Four zero-draw Shop owners remain explicit; no row was removed. Largest named aggregate reservation was 53,020,360 bytes under the 96 MiB ceiling, including the one-file model-view workspace. This is accounting of named owned/reserved inputs and workspaces, not a measured process RSS claim.

The evidence binds all source hashes, the exact candidate report, body hashes and retained capture hashes. It establishes candidate body field equality with the captured source observations. It does not establish which file the server originally opened, matching live source generation, CLIENT materials/LOD, geometry upload, world publication, or a live GROUPS transaction. Every corresponding authority flag remains false. No server capture, accepted APK rebuild or service restart was performed.
