# Post-trick LOD numerical stage

`coh_group_lod_apply_file_defaults` implements exactly the numerical stage in original `Common/group/groupfileload.c:groupSetLodValues`. Its input is explicitly the state **after** `groupSetTrickFlags` has applied original trick and CLIENT `ModelLODInfo` semantics. This adapter does not supply or prove that missing stage. In particular, feeding it saved-definition wire values does not reconstruct client visibility policy.

Original precedence is retained:

| Field | Source rule |
| --- | --- |
| Near and near fade | Preserved from prior trick/CLIENT state |
| Far and far fade | File values replace prior values only when from-file is set and from-trick is clear |
| Scale | File value replaces prior scale whenever from-file is set; zero becomes one |
| Missing far, with model | Ten times model half diagonal plus shadow distance plus ten; marks autogenerated |
| Missing far fade, with model, no trick | One quarter of final far; marks autogenerated |

From-file application clears autogenerated only in the no-trick far/fade branch. Other flags are preserved. Negative finite values are not clamped; the original does not clamp them. Fields the original does not read, including unused file values and model bounds when no far default is generated, need not be populated. Active state and results must be finite, flags boolean, and an active model box ordered; overflow refuses atomically. The kernel has constant work, no allocations, and publishes a complete result only after validation.

`check_group_lod.py --output receipt.json --sanitize` compares 4,096 deterministic fixtures byte-for-byte with the unchanged extracted original function using explicit fixture-owned Model and GroupDef structures. Native malformed/refusal rollback controls execute separately; release, ASan and UBSan results are retained in `evidence/group-lod-host.json`. Source pins include the original file and math macros. The host reference itself is not sanitizer-qualified. LeakSanitizer is disabled due to sandbox process-directory restrictions. Consuming targets must disable floating-point contraction and fast-math reassociation, as the supplied checker does.

Remaining required ownership includes original trick resolution, CLIENT auto-LOD records and model generation/loading, inherited parent-fade/material/draw state, generation binding, admitted assets and visibility selection. Numerical success grants no resource, world or renderer authority. There is no Android or physical-device qualification for this isolated kernel yet.
