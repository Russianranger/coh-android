# Retained source-body to rigid CPU geometry bridge

`coh_source_rigid_create` consumes an actual immutable `CohSourceBody` only after complete rigid CPU preparation succeeds. The request supplies the whole-join source ordinal and external material callbacks; geometry path, full model name, body digest, asset generation and graph node are derived from the retained opaque owner. The immutable lease also exposes separate graph/catalog generation labels and resource-owner generation counter, with original source/run/resource digests. These labels do not independently prove live generation.

The graph node identifies a definition, not a unique placed world instance or authoritative character/world pose. Supported ordinary rigid GEO versions follow the renderer adapter; verification of all 391 source headers does not imply CPU stream support for every version. Zero-draw source owners refuse before material callbacks and remain recorded in the source graph.

On failure, input body, output owner and report remain unchanged. On success the caller body pointer becomes NULL, and the bridge holds both source owner and renderer resource until retirement. Retirement releases renderer/material pins before the body. The caller must retain the actual loader and borrowed graph through this lifetime and serialize access. Borrowed views must not outlive their owner; control/output storage must be disjoint from opaque/source storage as documented by each API.

Budgeting adds current retained body/index/selection/join/catalog/snapshot/graph/profile ownership, bridge/scratch reservation and caller external allocations. The same loader reservation is charged once; historical peak is checked against it, not subtracted from unrelated owner totals. Caller external reservation includes other old resources, callback/material/digest work and GPU ownership. The module creates no GPU publication.

This bridge preserves the registered procedural exact-cold-capture evidence kind. A verified file body has derived origin within that scoped fixture; direct historical open observation remains false. CLIENT trick, texture, material, LOD and effective render state remain independent prerequisites. Material callbacks and their generation remain external; test callbacks are explicitly fixtures. Assets-admitted, client-materials-available, live-generation and world-authority flags stay false; unresolved CLIENT semantics stays true.
