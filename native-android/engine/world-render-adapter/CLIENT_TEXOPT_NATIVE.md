# Compact native historical CLIENT TexOpt input reconstruction

`coh_wr_texopt` admits the exact retained CLIENT `tricks.bin` through the protected asset loader, validates all ordinary persisted TexOpt fields, and creates independent immutable records using original CLIENT `setupTexOpt`. Python is qualification tooling; Android consumption is native C. The module grants no BasicTexture, TexBind, material, GPU, active-generation or world permission.

## Authentic inputs and generation boundary

The cache must be exactly `data/bin/tricks.bin`, 13,537,052 bytes, SHA256 `cf9595e54bc65a40d2dddc3a5a13c475d7c2ce07a96420e6001b0e2312926bc1`, observed schema word `5ba1b0e3`. Surface preparation must come from the opaque native `coh_wr_surface_states` owner, whose exact cache is 15,380 bytes, SHA256 `9c4a5aab4c2bffb99eb2416e76a692449ee26927beed3cdd86dece02af2b2aac`. Both are members of the retained historical client cache archive SHA `5d7f5b5c1932cf755f4063092ba56a30b16d1a705c6716a98b71f9738d61c051`. Retained compressed bodies and original acquisition identities are documented in the earlier cache/surface evidence.

The nonzero historical import label must match between cache and Surface owners. This prevents mixing local preparation transactions. It is not a MapServer, actor, scene, active CLIENT or asset-generation proof. The actual body identities, historical producing manifest and source qualification remain distinct from that label. No callback label or source-only field creates current material authority. Compiled parse-table CRC is not recomputed; the complete exact cache SHA and its pinned observed CRC are both checked.

## Native cache admission

The loader must be configured with total capacity no larger than the supplied reservation. The entire reservation is charged before acquire. Full SHA and exact acquired path/generation are checked before parsing. All 1,585 source dependency entries are bounded and checked in original case-insensitive order. Every TexOpt source filename must belong to that dependency table and carry the matching persisted timestamp. Those normalized timestamps are dependency observations, not live generation proof.

All 14,715 TexOpt records are validated with the complete six-table persisted wire grammar: fixed-width scalar/string/vector data, embedded lengths, redundant-name omission, U32-to-U8 casts and float32 fields. Nonfinite floats refuse. First struct-param and InternalName values must match exactly. The 3,644 Trick record spans are bounded but their Trick/AutoLOD semantics remain opaque. No complete Trick/material dictionary claim is made.

Admission allocates one fixed metadata owner and pins one immutable loader blob. It keeps original row/slot order. An in-place heapsort creates an index without eager material objects or hidden sorting allocation. Case-insensitive lookup chooses the highest original ordinal, matching original reverse-order non-overwriting postprocess insertion. Every raw row remains present, including shadowed or unsupported postprocess rows.

On the qualified 64-bit host, metadata is 319,752 bytes; the raw blob is charged through the loader reservation. Each constructed source/postprocessed record is 6,192 bytes. These are host observations; Android ABI build/execution and whole-process working set are not inferred.

## Original CLIENT postprocessing and immutable records

Private exact original enum/structure/table declarations are checked against readonly source. Original source functions `setupTexOpt`, `texOptNeedsMultiTex`, `texOptFlagsFromName`, `strStartsWith` and `strEndsWith` are retained without body edits. Owner-local macro adapters provide bounded string storage, the exact historical Surface supplier, source table-owner identity and diagnostic counts. Production code has no shared mutable postprocess globals. Original source symbols/tables remain private to this module.

Original zero allocation and indirect empty-string-to-NULL rules are preserved. The 4 KiB owned string arena keeps original stored values even when postprocessing clears or moves a pointer; full owner retirement frees it once. No individual arena pointer is freed. Generated source strings have checked arena capacity. Original shared-memory behavior is not exposed: the qualified path is CLIENT=1, SERVER=0, shared_memory=false.

`coh_wr_texopt_record_source_view` exposes original stored values before setup; `coh_wr_texopt_record_view` exposes the resulting historical postprocessed values. Their stage field distinguishes the two. Both retain raw-cache SHA, source ordinal, highest-ordinal table owner and owner source filename. Earlier parser alias-token values remain recoverable in the retained exact raw cache. This keeps source-defined transformations auditable.

In particular, original setup removes `none`/`texture_name` placeholders, removes irrelevant second material layers when Mask is absent/white (except fancy water), resets irrelevant scales/scrolls, selects texture modes, computes specular/lighting defaults and augments flags from names. Its explicit-Base1 branch can generate the literal reference `white`. This is preserved source behavior, not creation of a white texture, asset resolution or a renderer fallback. Every such asset reference still needs qualified resource ownership.

Cement is missing only from the exact historical Surface dictionary. Original setup consequently applies its explicit missing-state-to-zero branch. No global/live missing-state claim is made.

One exact cached identity, ordinal 10,499 at offset 8,973,768, has name bytes `ArchEnt_INT_Elevator_Door_G` followed by `ef bf bd`, sourced from `TRICKS/SPECIAL_BUILDINGS/ARCHITECT_ENT/ARCHITECT_ENT_TRICKS.TXT`. It is preserved and wire-validated. Record postprocessing refuses it with UNSUPPORTED because original CRT/name helper semantics have only been qualified for bounded ASCII. No name is repaired, substituted or removed. Its necessity must be determined through actual resource closure before publication.

Constructed records own their strings and survive cache, loader and Surface retirement. Publication occurs only after full decode, source owner lookup, original postprocessing, callback status checks and cancellation checks. All refusals preserve the caller's owner and release candidate allocations/pins. No renderer integration is performed here.

## Budgets and qualification

The cache charges its fixed owner, whole externally configured loader reservation, 16 KiB module preparation/control reserve and 16 KiB module static-data reserve before acquire/allocate. Records require external accounting at least sufficient for cache metadata, whole loader reservation, Surface owner/static data, all previous records and other live resources. Record admission adds its own owner and the same module preparation/static reserve. Code mappings, allocator/compiler/sanitizer/runtime overhead and provider/digest peaks are external. This is a component accounting contract, not a measured whole-process cap. The host fixture reserves additional external memory for its eager independent original-source oracle and sanitizer runtime; no accepted Android budget is changed.

The qualifier freezes all source dependencies before helper import and executes admitted helper source directly. It reconstructs original typed parser storage from the actual cache, executes original CLIENT Surface loading/lookup and reverse-order postprocessing, and independently compares every stored and computed field, layer, default, diagnostic and duplicate owner. Native input/stage views are also checked. Release, ASan and UBSan cover the complete supported corpus, explicit unsupported identity, malformed whole-body hash, digest/allocation failure, generation mismatch, cancellation, budget boundaries and old-owner preservation. LeakSanitizer remains disabled under the container's `/proc` limitation. Original warning allowances apply only to original oracle translation units.

This closes historical TexOpt wire/storage/postprocess input reconstruction. Exact active Basic namespace/overlay ownership, original composite factory, directory/locale/scene/definition substitutions, complete Trick/AutoLOD semantics, capability/fallback profile, layer body/texture/GPU ownership and matching live generations remain required before material or world publication.
