# Native historical CLIENT texture path inheritance

`coh_wr_texopt_lookup` executes the original `trickFromTextureName` body over the immutable exact historical TexOpt cache. It returns a completed lookup observation, original name-derived flags and, on a match, an independently owned postprocessed TexOpt record. It does not create an active BasicTexture, TexBind, shader, texture asset, GPU resource or renderer publication permission.

Original direct lookup copies the full path, normalizes backslashes, finds the basename, removes its final extension, then removes the final `#` locale marker. If direct lookup misses, the original path is restored, made relative to the first case-insensitive `texture_library` substring when present, and progressively shorter directory keys (with trailing slash) are tried. The closest matching directory wins. Name-derived flags use the ORIGINAL full path and winning postprocessed flags; they are not derived from the normalized lookup key. A complete historical miss still computes original name flags from zero. Original key collisions choose the highest source ordinal through the immutable cache's reverse-order source ownership rule. No directory key is converted to a basename match.

Production retains unchanged original bodies for `trickFromTextureName`, `texOptFlagsFromName` and `strEndsWith`. Only the lookup function signature adds a private stack context. Owner-local callbacks implement immutable table access and prepare the matched record; no global mutable state is introduced. ASCII helpers and slash conversion reproduce their qualified source domain. Original StashTable source is retained in the qualifier dependency map; original stash primitive execution is not claimed by the independent FNV observer.

The accepted domain is nonempty ASCII full texture paths with a slash/backslash and nonempty final component, fewer than260 bytes. The260 bound comes from original `texOptFlagsFromName`'s `MAX_PATH` buffer, despite the lookup body's larger1200-byte buffer. Paths ending exactly at the `texture_library` substring or slash are refused before the original directory loop can index an empty string. Basename-only paths are refused before the original NULL `slash++` expression. These are explicit input-domain refusals, not source-body repairs, normalization alternatives or fallback behavior. Non-ASCII names remain unqualified.

The historical Surface/cache preparation labels must match. They remain local historical import labels, not active CLIENT or server/resource generations. An additional16KiB fixed lookup stack/control reservation is charged before callbacks/allocation; matched record preparation charges its own documented cache/Surface/external/record reservation. The result and record pointer publish together only after the entire operation and final cancellation check. Failure preserves caller outputs and frees any candidate record. Output memory must be disjoint and writable, outside borrowed loader blobs. A matched record owns its strings independently; the plain result copies its matched key, cache hash and provenance fields.

The qualifier independently reconstructs the exact historical typed cache and original postprocessing, then calls the unchanged original lookup with its original signature using an independent table observer. It compares paths generated from every supported actual TexOpt name, case variants, directory keys, locale and extension handling, backslashes, name flags, direct/inherited priority, duplicate ownership and complete misses. Invalid-domain, output-alias, budget/overflow, allocation, generation mismatch and every sampled direct/inherited/miss cancellation point preserve transaction rollback.

This does not establish absence from any active CLIENT dictionary, substitute a global default material, or resolve its composite. The immutable cache and texture bodies are checked before and after qualification; no network, recapture or CLIENT startup is required.

Active namespace/overlay selection, Basic/composite creation and ownership, locale/scene/definition substitutions, texture availability/LWC stage, capability profile, complete Trick/AutoLOD rules and matching resource/GPU/live generations remain separate prerequisites. Android/Thor execution and actual world/material acceptance remain unqualified by this host component.
