# Canonical BGRA32 namespace-body adapter

`coh_wr_tex_rgba32` closes the actual retained grey texture's unsupported CPU pixel path in new resource-only files. The protected DXT loader, renderer, common build files and GPU paths are unchanged. The constructor takes an actual namespace owner and row, acquires its real source body lease (including the existing whole-body hash recheck), validates the complete DDS layout, and makes an independent immutable RGBA copy with copied path, source generation and whole-body SHA. It releases the source pin only after the copy is complete. The namespace and its provider can then actually retire without invalidating the decoded result.

Original CLIENT `ddsLoad` selects `TEXFMT_ARGB_8888` for pixel flags `0x41`, 32 bits and alpha mask `0xff000000`. It does not interpret the RGB masks or row pitch. `texCopyDirect` submits the payload as tightly packed BGRA bytes when BGRA is available, or swaps red and blue in its mutable upload copy for RGBA when unavailable. This adapter preserves that pixel result, row order and every alpha byte. It deliberately admits only canonical BGRA masks, zero FourCC, 2D dimensions at most 16,384, consistent declared pitch/linear size, and an exact whole payload. Other masks/layouts refuse rather than becoming a generic mask decoder. It does not modify the pinned source, the cached TX2 prefix or cached alpha policy.

The original upload loop uses an inclusive mip-count test. Safe admission here permits a complete chain terminating at 1x1, or source count zero with only the base level. Partial chains refuse. A supplied `skip_mips` value follows the unchanged original `ddsLoad` reduction arithmetic and must leave at least one level. Choosing that value from graphics or entity settings is outside this adapter. No missing mip is synthesized, no padding is silently skipped, and no vertical flip, alpha clearing, fade, premultiplication, TexOpt, default, composite, sampler or material policy is applied.

The authentic input is the already retained run 39078874753 artifact 12118720382: 12,308 bytes, SHA256 `87a999e6c1c003b96a9fa169ce11637b61eb696766517e063fafce73fdc39c24`. Grey is exactly 894 bytes, SHA256 `b628966e91a864f9edcb0634605823a7ef3d8e2305f36d1a9f6e9834b018a013`: a 426-byte cached wrapper and 468-byte DDS, with 8x8, 4x4, 2x2 and 1x1 levels of 256, 64, 16 and 4 bytes. Its protected decoder's historical unsupported result remains accurate for that decoder; this separate adapter adds the missing canonical RGBA32 path.

All preparation is synchronous on one owner thread. Candidate storage is never published on refusal, including late cancellation. The complete source pin remains held across cancellation callbacks, so source destruction refuses. Successful output owns a single bounded allocation and no source lease. Known exposed metadata/body aliases refuse; output and request storage must also remain outside the opaque namespace/provider storage as documented. Getter and destroy output aliases against the entire decoded owner are checked. Source provider, callback and other runtime peaks remain external obligations.

Budgets charge exact requested decoded-owner allocation bytes, a fixed 16 KiB own preparation/control reserve, and caller external bytes. The latter must cover at least the source owner's full recorded aggregate reservation before acquire; this minimum is enforced. That conservatively retains the source owner's configured loader and preparation reservations during overlap. The qualified host module frame sum excludes namespace/loader/callback/libc and Android frames; no allocator overhead, RSS or global-memory authority follows.

The new focused qualifier extracts unchanged whole original `ddsLoad` and `texCopyDirect`. Win32 wire/storage, requested skip, file allocation and GL upload calls are explicit observers. Both the BGRA capability route and the original in-place red/blue fallback execute without a GL context. Four actual-grey reduction cases and patterned complete/base-only, rectangular and non-power-of-two controls compare every mip's dimensions, source level and RGBA bytes. Patterned colors and alpha distinguish channel order and preservation that grey's neutral pixels cannot. Negative controls cover masks, formats, dimensions, exact chain length, truncation/trailing data, source read/hash failures, allocation and cancellation positions, source destruction during callbacks, live-lease refusal, budgets, aliases and actual post-copy source retirement. Semantic production mutations must be detected.

The controlled provider fixture charges known body/context bytes plus a declared 256 KiB external allowance; this is not a measured complete test-process peak. Exact decoded allocation and aggregate reservation values for the four authentic-grey cases are retained in each mode, with the source owner's full reservation kept separate. A last-pixel-written observer triggers cancellation only after the final actual pixel store, independently of discovered poll counts. Tracked calloc/free blocks and provider holds/drops must balance. ASan executes with LeakSanitizer disabled because this host cannot enumerate ptraced process tasks; no LeakSanitizer result is claimed.
