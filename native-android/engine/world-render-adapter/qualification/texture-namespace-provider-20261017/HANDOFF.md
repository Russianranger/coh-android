# Declared immutable texture provider namespace

The new resource-only `coh_wr_tex_namespace` owner implements bounded cold texture selection over an actual caller-owned immutable data-root/PIGG provider. It stores the merged path tree, all successful cached-header rows and the first basename lookup owner. Selected bodies use real pins from the existing asset loader. This is a native producer prerequisite, not evidence that a historical metadata inventory is a complete current CLIENT namespace.

The production API requires ordered data-root snapshots, actual PigSet order, unique source generations, root spelling, file/directory spelling and timestamps, mode, production override policy, folder exclusion, ignore prefixes, quickload and LWC state. The provider must supply and enforce one real lifetime lease covering every source reader and digest context. No `complete=true` attestation is accepted. The caller still has to produce the actual complete catalog; this module performs no OS scan or watcher update and does not recover missing history from normalized imported files. Nonempty directories may be implicit only when first-creation spelling/order remains exact; empty directories must be explicit.

| Source mode | Cold tree construction and texture scan |
| --- | --- |
| Development | Filesystem roots in reverse search-list order, then PIGGs only for paths already admitted by the filesystem/cache query. |
| Development dynamic | PIGGs first; the non-quickload request adds the texture filesystem tree afterward. Non-quickload texture enumeration excludes leaf nodes never seen in the filesystem. Quickload uses the PIGG tree directly. |
| I like pigs | Filesystem roots in reverse search-list order, then every admitted PIGG. |
| Pigs only | PIGGs only. |

Both-PIG path collisions select the lower/equal virtual location; both-filesystem collisions select higher/equal. Mixed PIG/filesystem selection preserves the original directional timestamp equality or positive 3600-second offset check. The first component spelling remains retained. Filesystem dot entries, production bans, exclusions, original ignore-prefix behavior (including its mixed-case slash-search detail), underscore subtree pruning and extension matching remain explicit. A sorted sibling tree is traversed in depth-first order; plain full-path lexical sorting would differ. Later LWC passes must use the actual predecessor owner produced by this module, with unchanged old roots and PIGG prefix. A matching preexisting basename skips the load. Duplicate successful Basic rows remain in the array, while the hash lookup and all duplicate names use the first owner/key spelling.

The owner parses only the original cached `TextureFileHeader` prefix and retained TX2 bytes, not a DDS codec. It preserves original cached names, directories, dimensions, flags, fade, alpha, file offset/size, initial header-derived Basic flags and exact cached mip bytes. The source body SHA is computed from the actual selected bytes and checked again on reacquisition. The shared loader is always queried with the winning source's exact generation; its separate latest-mount lookup policy is never used to choose a namespace winner. PIGG name IDs must equal their internal ordinal, matching original `PigFileGetFileName`/`PigFileFind`; the shared loader's more general record mapping is not used to relax that invariant.

Safe admission is deliberately stricter than unsafe original domains: ASCII canonical relative paths, 259-byte virtual paths, bounded names/header data, nonnegative signed32 timestamps, finite fade and valid signed32 dimensions/payload sizes are required. The original JPEG consistency assertion is enforced. Unsupported HOGG, filesystem-only/absolute legacy fallback, watcher changes, malformed headers, I/O failures and other refusals abort the entire candidate. A partial namespace is never published.

Metadata views live until owner destruction. Each body acquire transfers one actual pin; byte views and borrowed aliases of that opaque handle expire on its sole release. Destruction refuses live body leases. All APIs use one owner thread. Public calls on an owner being observed by an external callback refuse with `COH_STATE` before touching arrays. The predecessor is guarded before the initial cancel/hold callback and remains guarded through rollback/provider drop. A failed provider hold acquires no lease. Successful holds, partial loader pins and heap blocks balance on every refusal.

Budgets charge all new owned allocations, caller input spans, the full configured loader reservation, a fixed 64 KiB own preparation/control reserve and caller external peaks. When a predecessor is present, external bytes must cover at least its known owned bytes plus its full configured loader reservation before any callback or source read. Actual provider/runtime/callback and library peaks still belong to external bytes; numeric generation equality grants no overlap credit. The native scanner is iterative with 130 fixed frames. The source tree and declared count limits bound preparation work; no frame-time, RSS or global-memory guarantee is implied. No loader provider is retired while a body is pinned.

The new qualifier executes unchanged whole original `FolderNodeAdd`, `FolderNodeFind`, `FolderNodeRecurseEx`, `FolderCacheMatchesIgnorePrefixAnywhere`, `fileScanAllDataDirsHelper`, `texFixName`, `texFillInBind` and `texLoadHeaderProcessor`. File/pool/stash/string storage and Win32 wire adapters are explicit observers. The original TexOpt lookup call is observed as NULL: effective TexOpt/reset/composite behavior is not qualified here. The outer `fileLoadDataDirs`, `FolderCacheAddFolderToNode`, `FolderCacheAddPig` and `fileScanAllDataDirs` functions are source-ported/reviewed around the declared descriptors, not executed as OS/runtime functions by this oracle.

The actual input fixture has 22 authentic cached bodies: fifteen existing avatar textures and all seven newly retained defaults from run 39078874753, artifact 12118720382. All bodies are individually size/SHA admitted before use. Grey's RGBA32 DDS is accepted by this header-only path and compared with the unchanged original header consumer; the protected DXT1/3/5 decoder's separate unsupported result remains unchanged. Another 8,936-row case uses only the authentic retained reference paths, with explicitly controlled generated headers, one chosen filesystem root and timestamps zero. Those rows are not authentic bodies or a reconstructed original namespace. Controlled cases cover directional timestamp endpoints, all four modes/quickload, duplicates, LWC predecessor preservation, source/digest/allocation/cancellation failures, callback reentry, late body mutation, filter policies, malformed inputs and a 258-byte deep path. Release, ASan, UBSan and an actual C-object/C++ call-link are required. Production semantic mutations must be rejected.
