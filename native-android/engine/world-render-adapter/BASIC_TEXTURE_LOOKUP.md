# Source-only BasicTexture lookup prerequisite

`texFind` is a different original lookup path from model `buildTexBindArrayFromTexNames`/`texFindComposite`: it removes exactly one leading `!`, calls positional `texFixName` and looks in BasicTexture's case-insensitive table. It does not strip arbitrary last extensions/directories, apply the PORTAL→invisible branch, or apply scene material swaps. The new native adapter queries only the existing opaque authentic cached-header subset and returns NULL-request/observed-header/namespace-unknown. Unknown never establishes global absence or licenses white/default fallback, nor permits skipping a higher-priority locale key. Returned header ordinal/SHA/generation identify source inputs only.

Strict API preserves the original safe domain and refuses bare four-to-seven-byte keys that would execute original `res[-8]` out of bounds. A separately named guarded API uses the already qualified isolated original correction: test original prefix distance before the negative-eight access. Guarded repaired cases do not claim unchanged-source semantics. Old APIs are untouched. Original extension checks are case-sensitive and strip the positional suffix even when its spelling is unrecognized; returned source TexFlags (TGA32/DDS64/JPEG8192) are not codec/material capability permits. Basic keys containing locale markers remain intact unless a positional suffix matches.

Every query has bounded ASCII128 input, fixed stack/control storage, output-alias checks against the old immutable owner and its pinned bodies, and explicit aggregate admission (existing owner/whole loader plus other peaks external;16KiB own nested/input/output reserve). The header alias boundary uses the already validated original32-byte cached header/name placement exactly as the frozen dependency adapter; it adds no independent header/body authority. No allocation, pin or ownership transfer is performed. Returned values are self-contained; the input owner/loader must stay alive while calling the query.

The oracle executes unchanged original `texFind` and original/explicitly repaired `texFixName`, with release-mode debug poison assertions disabled. String copying and the two-row table are explicit bounded host observers; they are not the active original stash/namespace. Two retained authentic Box/Bar bodies establish actual input identity; other query strings exercise source rules, not invented assets. Source functions, true original TexFlags enum, correction diff and all dependencies are hash-bound before helper execution and readmitted afterwards. Release/ASan/UBSan and semantic mutations cover positional/case rules, one-bang handling, PORTAL ordinary lookup, safe/guarded domains, bounds, aliases, missing subset keys and budgets. LeakSanitizer remains disabled for the established container limitation.

Original namespace creation still needs scan/LWC enumeration and overlay history. `texCheckForSceneSwaps` chooses matching swaps in reverse order; `texCheckForSwaps` applies the first successful locale lookup after scene permutation and excludes the actual white pointer. Therefore a future indirection planner must stop at a namespace-unknown candidate or unqualified white identity, rather than silently choosing another language. Active namespace/generation, complete scene/locale policy, white and other defaults, TexWord layout/inputs, capability profile, composites and GPU resource ownership remain unresolved. This module creates no fallback/resource and grants no material, live world or Android permission.
