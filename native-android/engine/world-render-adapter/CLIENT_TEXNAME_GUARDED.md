# Explicit guarded short-suffix policy

`coh_wr_texname_project_guarded` is an additive opt-in policy. `coh_wr_texname_project` and its source bytes remain unchanged. This policy closes only the original `texFixName` out-of-bounds short-suffix dependency; it does not provide a composite table, texture/material, default white resource, matching generation or world permit.

The isolated original-source correction is retained in `texname-guard-original.patch`. It saves the initial output pointer and requires at least eight traversed characters before examining `res[-8]`. The existing early return for fewer than four characters and four-byte suffix branch remain unchanged. Bare names of four through seven bytes therefore remain unchanged without a negative-index access. All key/raw-name bounds are still enforced before the original oracle executes. The original oversized-input walk defect is not repaired here; names exceeding the supported key size still refuse.

`texname_guard_candidate.py` requires the exact unchanged original function SHA before applying precisely two source substitutions. The upstream source file is never modified. Qualification retains original and corrected function hashes, original and corrected full-file hashes, and the exact diff. The corrected function is compiled inside the same original five-function lookup chain used by the strict qualifier. Corrected-source cases are explicitly **not** unchanged-original cases.

The native guarded function is separate to preserve the strict baseline byte for byte. The qualifier first admits the exact strict receipt and all of its source dependencies. Every strict-success case must produce byte-identical strict/guarded projections and match the unchanged original chain. Every newly supported short case must match the corrected-original chain under release, ASan and UBSan. The actual36 captured short names are counted dynamically and must all succeed; they remain raw composite lookup keys rather than actual asset bindings. Both stash hit and missing outcomes are observer fixtures. A missing table entry never becomes a native white binding.

Negative controls preserve overlong/non-ASCII/missing-field/alias refusal and atomic output behavior. A mutation restoring the strict short-name refusal must fail the guarded suite. Mutating the original function preimage must fail candidate staging. Inherited material/BasicTexture/locale swaps, capability-dependent texture construction and effective material/LOD/lighting resolution remain required as listed in `CLIENT_TEXNAME.md`.

Run `check_texname_guarded.py --output /tmp/FRESH-guarded-name.json`. This is host source qualification only: no original CLIENT binary/process, Android, server, real material lookup or world session is claimed.

This qualifies the isolated guard's pointer-base handling without executing the original undefined short-name cases or widening oversized-input support.
