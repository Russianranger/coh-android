`coh_wr_tex_namespace_lookup` connects original `texFind` name semantics to a real immutable `CohWrTexNamespace`. The previous Basic lookup adapter searches only imported texture headers and cannot establish a selected row or absence in the declared full namespace. This function returns a copied row/path/generation/hash from the actual namespace owner. A miss remains absence only from that caller-supplied immutable snapshot.

One leading `!`, positional source extension tests, case-sensitive format flags, case-insensitive Basic-key lookup and first retained basename ownership are preserved. No directory stripping, scene swap, `PORTAL` special case, white/default fallback or suffix-locale behavior is added. Strict source-undefined bare lengths4..7 refuse. The explicit guarded option selects the already qualified two-location `texFixName` correction. Truncating and non-ASCII domains refuse. Copied rows require the same live namespace to acquire a real body; no lease or provider attestation is created.

The complete source namespace aggregate reservation is required before querying. The function adds16KiB own control plus named query/limits/result spans. It allocates no memory and invokes no provider, digest, read or cancellation callback. Returned identities have no pointers and can be inspected after real provider retirement, but cannot resolve a retired row. The caller must keep opaque provider/source storage disjoint from the output; public metadata/input aliases are additionally rejected. Initial source alpha is not promoted into the effective default phase, TexBind, composition, material, GPU, current CLIENT or world authority.
