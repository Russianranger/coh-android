# Complete historical persisted TexOpt wire decoder

`texopt_full_cache.py` extends the frozen prefix contract with every ordinary persisted TexOpt field, including all embedded scale/color/fallback tables. It decodes one immutable record at a time. The exact actual cache has 14,715 TexOpts; every record consumes its complete declared byte span. The 96 primary serialized entries expand to 2,251,395 scalar/string observations across that historical array.

The strict source schema extractor admits the pinned `tricks.c` hash and six exact table declarations. Unknown declarations/token families, dynamic structures, unsupported fixed counts and missing subtables refuse. Redundant names and End markers are omitted exactly as the original binary reader does. Strings remain raw bytes; U8 words use the original U32-to-U8 cast. Float words decode as IEEE float32 without inventing effective-material finiteness policy. Nested record lengths and aggregate per-record field/depth limits are validated. No partially decoded result is returned on failure.

The qualifier compiles the unchanged original parse-table declaration text with an explicit wire-type observer macro harness. Source field offsets/default expressions are not original runtime struct layout: observer macros replace those attributes while preserving serialization kinds, fixed counts and nested tables. The unchanged original `ParserReadBinaryTable`, scalar/string/struct/fixed-array readers and `ReadPascalString` execute over the actual cache. TokenStore observer callbacks emit every decoded scalar/string. The entire 11,539,670-byte transcript equals independent Python decoding, SHA256 `b7494736082e979345d62d0a46666972d666894613528c0166f39355de36acfe`, in release, ASan and UBSan. This tests complete wire grammar, not original native TexOpt storage, compiled schema CRC, dynamic allocator ownership or parser defaults.

Additional controls corrupt each embedded payload length and refuse wrong source text/ordinals. The qualifier binds source dependencies and actual cache SHA before/after execution. LeakSanitizer remains disabled in this container; the original unused `dataloc` warning is allowed without changing the copied source function.

The decoded actual `asphalt_squaremask` record includes Surface `Gravel`, Base1 `asphalt_squaremask.tga`, Multiply1 `asphalt_filler.tga`, BumpMap1 `asphalt_squaremask_bump`, and literal `none` placeholders in several other layers. Those placeholders are still historical parser input. `setupTexOpt` changes them and many other fields before effective material lookup. The new decoder does not prematurely normalize them or infer source resource availability.

Remaining work is original CLIENT `setupTexOpt` qualification with exact enums and original structures, explicit surface-state dictionary provenance, reverse-order duplicate insertion, and historical ownership; then active Basic/composite namespace, capability/fallback profile and matching generation admission. Raw text tokenization, complete Trick/AutoLOD semantics, native material storage, setup/postprocess, Android execution, active generation, GPU/material/world permission are not claimed by this component.
