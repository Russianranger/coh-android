# Native historical CLIENT surface-state input owner

`coh_wr_surface_states` is a bounded native immutable importer for the exact retained `seqstatebits.bin` cache and original code-defined state list. It supplies historical source state indices for original CLIENT `setupTexOpt` qualification. It grants no current entity, animation, material or world authority.

The raw cache is 15,380 bytes, SHA256 `9c4a5aab4c2bffb99eb2416e76a692449ee26927beed3cdd86dece02af2b2aac`, observed schema `6b0e7f06`. It was recovered from the already retained C/F-qualified client cache archive (same archive as tricks.bin); no new network request, build or server/CLIENT execution occurred. Exact raw bytes are hashed before parsing; generation is an explicitly historical import label. The owner copies names and does not borrow caller bytes after success.

Original `seqLoadStateBits` starts with 111 code-defined states, reads 764 cached names/flags, uppercases cached names, retains the first duplicate and appends new names with consecutive indices. Actual cache produces 875 states. The native importer preserves that order and refuses unsupported non-ASCII names, overlong names, malformed lengths, trailing data or capacity exhaustion. Its fixed capacity 876 matches pinned `TriggeredMove.h`; no cap was increased. The generated core is independently compared against the actual original initializer, source constants and load function in qualification.

The qualifier executes the unchanged original `seqLoadStateBits`, comparator and `seqGetStateNumberFromName` in CLIENT mode against the actual ordered cache records. ParserLoadFiles is an explicit cached-input observer supplying those bytes; production file lookup/cache consumption is not re-executed. Every historical name/index and lower-case alias is compared to native lookup. `Cement` is an actual TexOpt surface input that is not a state name in this dictionary; native lookup returns NOT_FOUND and preserves the result. Only a later qualified original setupTexOpt path may apply that function's explicit missing-surface-to-zero rule.

Native owner/test sources compile with strict warnings. Existing const/sign warnings are permitted only in the unchanged original oracle translation unit. Release, ASan and UBSan cover every state, all 766 cancellation points, hash refusal, allocation failure, aliasing and budget boundaries. LeakSanitizer is disabled for the container `/proc` limitation; ASan and UBSan execute separately.

Memory admission charges the owned fixed array, full borrowed preparation input span, external live/provider/digest/runtime peaks, 16 KiB module stack/control reserve and 16 KiB immutable source-core reserve before digest/allocation. The latter covers the core's static 111-row table. Compiler/sanitizer/libc/callback stack overhead must be included in external accounting. This is a component contract, not whole-process peak-memory qualification. Lookup performs at most 875 bounded name comparisons; it belongs in material preparation, not a per-frame visibility loop.

This source input owner is independent of protected renderer/assets/animation modules. Android build/execution, active CLIENT generation, effective TexOpt semantics, compiled parser-schema CRC recomputation, material/GPU/world publication remain unqualified.
