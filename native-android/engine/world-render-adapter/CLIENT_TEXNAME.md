# Bounded original CLIENT composite-name projection

`coh_wr_texname_project` implements the name-only prefix of original CLIENT texture binding. It publishes a copied immutable value and no TexBind, BasicTexture, fallback texture, shader/material, generation or draw capability. Both original branch labels (PORTAL and an empty texture table) remain labels, not actual invisible/white resources. A lookup result is a **composite table query**, not a cached texture path.

The source order is:

1. `buildTexBindArrayFromTexNames` removes the **last** period and everything after it, regardless of the extension. This mutates the original shared texture-name table; the projection instead copies the visible result. A case-insensitive PORTAL substring selects the original invisible-bind branch before any composite lookup. A wholly empty table selects the original white-bind branch; a missing partition/name is not an empty table.
2. `texLoad` invokes `texFindComposite`. Composite lookup skips exactly one leading `!`, then `texFixName` can strip another four- or eight-byte suffix. Source suffix removal is conditional on period position, not whether the suffix is recognized. Case and directories are preserved; there is no basename extraction or automatic lowercasing here.
3. `texCheckForSceneMaterialSwap` chooses the **first** case-insensitive matching scene-material swap. Its destination is queried directly and is not normalized a second time or recursively swapped. These are scene material swaps, distinct from BasicTexture scene swaps or inherited definition swaps.
4. The original composite stash lookup follows. Original `texLoad` returns white if this lookup misses. The projection does not implement that fallback or imply the queried table entry exists. A missing composite remains an unresolved dependency for resource publication.

The source helper has unsafe input domains. `texFixName` reads `res[-8]` for a four- to seven-byte bare name unless its earlier `res[-4]=='.'` branch fires. Its copy is bounded to128 bytes, but its pointer walk follows the original input length. The bounded helper refuses those short unsafe cases and keys exceeding127 bytes instead of reproducing out-of-bounds behavior. It also limits raw names to255 bytes and scene swaps to256 rows, requires ASCII, and preserves output on every refusal. Strings and swap arrays aliasing output refuse. Outputs have deterministic zero tails.

The actual source corpus contains1769 unique root-reachable raw partition names. Thirty-six reach the unsafe short-name domain after producer extension removal, including `white`, `white.tga`, `black.tga`, `blue.tga` and `dirt.tga`. The complete list is retained in the qualification receipt. These references remain unresolved; they are not removed. A separately reviewed isolated repair of the original suffix guard could qualify a future supported policy. This helper presently preserves its strict refusal boundary.

The source oracle compiles these five functions unchanged: `buildTexBindArrayFromTexNames`, `texLoad`, `texFindComposite`, `texCheckForSceneMaterialSwap` and `texFixName`. Narrow observers replace stash contents, actual loading, source globals and utility functions for the bounded ASCII/length subset. Tests observe query key, original mutated name, branch and exact first-swap identity. Both stash hit and missing-to-white behavior are observed as **fixtures**; no original CLIENT process or real resource lookup executes. Unsafe original function inputs are never executed by the oracle. Authored cases cover double extensions, one/two leading exclamation marks, suffix case, periods in directories, Portal bypass, duplicate swaps, no chaining, empty table, bounds, aliases and atomic refusal. Mutations changing last-extension selection or allowing swap chaining must fail.

Fixture names additionally include exact retained Neon/Shop_tailor partition identities and the previously qualified Box cached-texture example. Their provenance pin files and the complete captured-source report are hashed dependencies. Box remains unrelated to Atlas ownership and its short `Box-1` key is explicitly refused. A name match to an authentic manifest never establishes effective composite/material or asset generation.
