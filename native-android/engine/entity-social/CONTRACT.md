# Atomic raw team, supergroup and league phase

`coh_social_phase_read` consumes the original post-workshop team-up-to-date bit,
optional whole team list, mandatory supergroup statistics body, league-up-to-date
bit and optional whole league list. It stops before the attribute-description
present bit. A skip bit preserves explicit absence, not an empty replacement
for prior-generation social state. No caller state is applied.

The child source qualifications remain distinct: team/league execute whole
original producers and consumers; supergroup executes its whole producer and
an independent bounded model, without executing the original consumer. This
composed phase qualifies exact source fragment joins at matching absolute bit
positions and both alignments. It does not execute the whole enclosing original
ALLENTS function. Source-order files are pinned; no framing or later grammar
is inferred from successful child decoding.

All output and reader changes commit together only after both skip bits and all
required children pass. Late league failures roll back prior team and supergroup
staging. Caller-owned output/workspace must use heap or arena. Reader, input,
output and workspace spans are pairwise disjoint with overflow checks. The
budget includes input, both enclosing PODs, every child workspace,8192-byte
stack reserve and retained bytes once within8MiB. The same team workspace can
be reused sequentially because each child commits into its distinct candidate
output, retains no input pointer and allocates nothing.

The source-fragment suite covers2000 compositions (all four skip combinations),
exact raw member/supergroup projections and final cursors. Truncations sampled
every31bits on selected compositions and the last bit on every composition,
mutations sampled every71bytes on selected compositions, trailing unread data,
aggregate budgets, alias refusal and late failure rollback run identically in
release/ASan/UBSan. Original source oracles are unsanitized. C++ linkage and
conservative emitted reachable stack sum are checked. Byte-array alignment in
the supergroup child uses the actual shared absolute cursor.

This is raw bounded staging. Original consumer qualification for superstats,
prior-generation state/dictionary admission, attribute-description/dynamic graph/
sky/slave tails, whole entity update and outer command framing remain required.
There is no Android execution, authoritative actor, ACK or real-server acceptance.
