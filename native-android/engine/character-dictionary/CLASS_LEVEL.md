# Bounded historical selected-class projection

This additive component selects one class and one level from the exact historical
normal/villain cache owners. It retains all source rows and category indices,
copying only four transposed attribute rows and the two minimum rows (690 words).
It avoids materializing every class/level table. Unknown category dependencies
refuse; original Pool/Epic fallback is preserved. Missing minimum arrays use the
original zero strength and -100 resistance defaults. Empty maximum arrays use
1.0; shorter arrays repeat their final value. Nonfinite values refuse the narrow
native profile. Source tables and names remain unchanged.

The oracle executes whole original classes_Repack, CreateCharacterAttributes and
TransposeArray on the actual parsed class trees. Explicit heap/earray pointer
adapters convert binary fixture storage to original array interfaces; category
lookup uses a declared pointer adapter over the separately qualified actual
category ordering. Parser retirement is observed and actual fixture allocations
are released after output. Original parser allocator/retirement, category lookup
inside this oracle, Win32 ABI and runtime startup are not executed. The source
oracle remains host-unsanitized; native selected projection is sanitized.

All owners, leased class input, output, workspace, native 16 KiB reserve and
retained bytes are charged before traversal under 8 MiB. Output is transactional.
This is historical source-equivalent data projection; it does not admit current
cache/SERVERONLY/shared generation, full powers, authoritative actor or ACK.

The original table schema serializes Defense twice and does not serialize
ElusivityBase. The second Defense field replaces the first; ElusivityBase stays
empty and transposes to source default1. Absorb is serialized last. The explicit
map preserves these original behaviors; it is deliberately not a permutation.

The projection occupies 2,880 bytes with an equally sized transient workspace.
Release/ASan/UBSan controls compare 195 selections: all 59 authentic class rows
at first/middle/final levels plus original-writer variants for missing minima,
empty/short maximum arrays and Pool/Epic fallback. An independent byte decoder
compares all 690 output words before native comparison; refusal controls cover
exact aggregate budget, later-field span corruption, aliases and invalid levels.
C++ linkage and actual compiler stack-frame totals are checked.
