# Full attribute-description raw transaction

`coh_attrib_description_read` adds the optional full description branch in new
files; the existing monitor parser and social code remain unchanged. It reads
original new-target/full flags, optional target owner, all ordered values and
buff bits, and the complete sentinel-terminated modifier stream. Each modifier
retains source hash, raw BasePower CRC, source type, conditional source name and
server ID, chance and magnitude. Source types0/1 have no name/ID;2/3 do. Unknown
power/attribute/source identities are retained as unresolved raw data, never
invented definitions or player identity. No gameplay/UI/contributor merging is
applied, and dictionary/actor authority stays false.

The full branch requires an immutable parsed attribute schema candidate with
an explicit matching whole-cache SHA and borrowed-input lease. The authentic
candidate has69 rows from7 categories; both original sender and consumer iterate
reverse categories and reverse rows. The new bounded cache importer validates
all actual schema bytes and original table CRC, independently of live runtime
cache/shared generation, as documented in `attribute-dictionary/CONTRACT.md`.
Every value stays associated with that exact original row ordinal. The full
schema is not replaced by a caller-supplied bare count or dense key dictionary.
A missing/mismatching candidate refuses atomically, without skipping values.

The source full branch is optional: initial `entSendUpdate` schedules attribute
sending by owner/tick modulo8; a full list additionally requires the saved combat
numbers window displaying. Team and league full bodies remain complete, with
source initial upToDate bits required zero. Nonzero active invention remains a
separate sender/consumer mismatch, not silently admitted by this change.

No heap allocation occurs in the parser. Output/workspace own bounded values,
256 raw modifiers and a64KiB NUL-terminated source-name pool; the256 limit is an
explicit local refusal bound, not an original engine limit. All floating words
must be finite. Raw target index does not establish a selected entity. Packet,
schema/cache input, expected pins, reader/output/workspace, optional cancellation
provider/context and callback scratch are disjoint and fully charged before
parsing. The named2MiB budget includes all those owned bytes plus16KiB native
stack and caller retained bytes. Callback stack/foreign-library sanitizer and
process resident-memory closure are not inferred. Cancellation may modify only
its declared provider context and rolls back reader/output even after the last
modifier. Body end is exact; trailing packet data remain unread.

Qualification reuses144 retained whole-original full sender/consumer cases and
120 retained original monitor cases. Original full functions, basepower/Auto
serializers and exact69-row candidate are source pinned. Actual gameplay value,
modifier filtering/hash, target, power lookup, UI and allocation interfaces are
explicit fixture shells; there is no original runtime/dictionary-generation or
whole engine claim. Native full output compares every row/modifier field/name,
every strict bit truncation, cancellation boundary, alias/budget failure and
sampled byte mutation. Additional controls join exact source-produced contributor
spans at256/257 counts, replace text at65535/65536 length, inject nonfinite words
and an out-of-range aligned Auto tag. Those are explicit synthetic local-bound/
malformed controls, not executions of extra original gameplay objects.

This standalone component does not yet change the frozen initial suffix owner
or authorize READY, RECEIVED_CHARACTER, application ACK, actor publication, real
server acceptance, Android application or physical Thor qualification.
