# Initial ALLENTS diagnostic owner

`coh_initial_update_diagnostic` composes the existing qualified full initial
header, generic create list, control, deletes, character groups1..6 and all ten
global suffix stages under one borrowed immutable packet and one aggregate
budget. Every body is consumed in source order. Only one large appearance,
character, inventory, social or dynamic scratch loan lives at a time. Compact
reports retain raw packet spans, one selected record, control and delete events;
there is no giant costume/character POD per entity.

The API always returns a refusal and leaves its public reader unchanged. Its
report may say that the supported raw syntax and exact trailing bit end were
validated. That report is a diagnostic candidate, not an authoritative actor or
complete application transaction. Selected ownership, current runtime dictionary
and dynamic-world generation remain separate admission gates. Source control
forced position is retained as a raw event, not applied to an invented actor.

The admitted initial list is full-create only (all required rare groups, full
modes, absolute position, all quaternion components, sequence); old/interpolated
records refuse. Same-packet deletes naming admitted creates preserve original
create/delete ordering; an unknown previous tombstone refuses, because this
contract has no previous world owner. Debug records, active invention, full
attribute-description dictionary and unknown appended game commands refuse at
the exact unsupported boundary. No bytes are scanned to find another message.

The trailing command profile is deliberately narrow. Original normalized nested
`SERVER_GAME_CMDS`15 has no body; `SERVER_BEGIN_BYTE_ALIGNED_DATA`197 advances to
the next byte and does not require zero padding. `entServerSendPackets` emits a
Pack1 zero terminator. The native owner requires that zero to end at the exact
qualified payload bit length. The legacy top-level +5 profile does not change
these nested IDs. A bounded command loop refuses unknown bodies instead of
accepting arbitrary serialized game commands. Full initial live packets may
require additional actual command handlers before this profile accepts syntax.

The named8MiB owned budget includes all explicit spans, dictionary, input,
retained allocator state, active charged loan and128KiB native stack reserve.
Parent/child retained charges subtract only objects/reserves already explicitly
included in each child. Existing4MiB badge/SG/buff aggregate limits remain. The
provider receives the maximum charge before allocation, including overhead;
populated partial loans release once even on acquisition failure. An enclosing
adapter rejects loans overlapping any parent object or immutable packet.
External callback/zlib stack, whole zlib sanitizer closure and process-wide
resident memory are not inferred from this native budget.

The fixture builder reuses the exact retained original-child list corpus and
successful Android suffix header, checks their complete SHA256 and verifies all
suffix source bytes still match the retained host qualification. It compiles
unchanged original complete control producers with the qualified full-update
fixture adapter and original bit writers. Explicit synthetic header/list/
control/suffix joins preserve each original boundary's bit alignment. This is
not execution of a complete original visibility/object graph, live transaction,
server cache generation, authenticated login, Android application or Thor world.
Existing selected/generic/outer parsers and their frozen regression code are
unchanged. No accepted APK is rebuilt.

Run `python check.py --output /tmp/new-proof.json.gz --suffix-evidence PATH
--sanitize`, where PATH contains the retained `fixtures.h`, `host.json` and
`package.json` from run38998532705 artifact12088426347. Source and external
fixture hashes are frozen before execution and checked again after qualification.
