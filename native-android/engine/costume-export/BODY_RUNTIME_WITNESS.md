# Prepared, disabled nonshipping BodyPart runtime witness

This extends the existing source-export preparation toward observing the genuine
loaded server dictionary. It does not qualify another allocator/reader leaf and
does not create a replacement costume dictionary. The accepted cache-hit and
original destruction providers, importer, runtime and Android APK are unchanged.

`stage_body_witness.py` pins the exact original BodyPart.c/.h, bones.h,
textparser.c and startup boundary. It writes only a fresh external disposable
source overlay. Optional `--costume-metadata` composes the existing costume
exporter, serially: BodyPart witness first, existing full costume export second.
The witness bytes are wiped before costume export; its fixed static reservation
remains allocated and must be charged alongside the existing4MiB exporter scratch
and every borrowed engine owner in a future source-process admission plan. No
server build or execution is performed by staging or qualification.

The staged original bpReadBodyPartFiles brackets its original single loader
call. Exact original ParserLoadFiles/Shared call sites report normalized shared
acquisition, actual located path, original binary return, text fallback and
original shared-loader return, filtered by the exact active BodyPart root.
Original loader calls/arguments/results and control decisions are preserved;
this is instrumentation of a separately built diagnostic candidate, never a
change deployed into the accepted server. The observed path is not a content
hash or filesystem freshness proof. The shared-hit path has no cache selection
claim. Unknown/repeated route facts and incomplete/failed loads refuse.

After a successful original return, the read-only producer copies every ordered
row's five nullable strings and six raw scalar fields (both bones, index,
num_parts, influence cost, U8 DontClear) into one bounded diagnostic byte span.
Null versus present-empty strings and signed32 bit patterns are preserved. At
the existing startup boundary immediately after loadCostumes(), it compares
those retained bytes against a streamed walk of the same live source-owned
rows, without a second catalog or allocation. Changed pointers/counts/contents,
reload before publication, malformed rows, strings over259 and rows outside1..29
refuse. Source owners and environment must remain frozen through each synchronous
walk and sink call; pointer/count/end checks do not detect concurrent same-count
mutation. Original global ownership is borrowed, not acquired or authenticated.

`COH_NATIVE_BODY_WITNESS_OUTPUT` is unset by default. In a future independently
qualified source diagnostic process, a bounded absolute output enables collection
and an exclusive new file. Existing files are never overwritten. Ordinary
write failure unlinks only the owned partial file; unlink failure returns5 and
reports CLEANUP_FAILED. Close failure returns6 and reports descriptor state
unknown, even if partial-file removal succeeds. All normal exits wipe witness
bytes and borrowed pointers. Return0 with the environment unset means disabled,
not an observation. The overlay's startup hook follows the existing nonshipping
exporter convention of a fatal diagnostic refusal; it is not installed in the
accepted runtime. Crash/power-loss and uncertain OS descriptor cleanup are external.

COHBW1 contains source-instrumentation pins and independently supplied
build/profile/run labels, normalized branch observations, actual located path
and complete pointer-free loaded rows. It has explicit zero current-Map/
generation and authority permits. There is deliberately no generation metadata
input, sequence counter, timestamp, packet-derived label or dictionary admission.
The source marker covers verified instrumented source/header pins, not an entire
compiled MapServer dependency closure. Configured build/profile/run IDs do not
self-attest the running executable. A file/hash alone never authenticates it.

The next unsupported boundary is **execution of a fully target-qualified
instrumented source process**, independently bound to its actual executable,
profile, run, coherent selected Map/session and original load-generation owner.
Exact selected cache bytes/freshness or shared-segment provenance remain
independently required. This host qualification cannot admit current-Map catalog,
COHCDI1 dictionary generation, complete ALLENTS character, selected ownership,
actor, READY, RECEIVED_CHARACTER, application ACK or world authority.

The source observer has a65,536-byte maximum payload; host x64 static state plus
numeric final status is65,860bytes. It performs zero new heap allocations. A
4KiB observer stack reserve exceeds the measured selected source frames; full
engine/libc/sanitizer aggregate stacks and borrowed BodyPart owner allocations
are external. These are observer-owned host measurements, not total MapServer
RSS/PSS, native-client memory or Android device headroom. No module or server
memory policy is widened. The observer is not on a GL/network/audio hot path.
No allocator fault injection is invented where the producer allocates nothing.

Run `python3 native-android/engine/costume-export/check_body_witness.py --output
/tmp/body-witness-host.json --work /tmp/body-witness-evidence` with a fresh work
directory. It runs Release, ASan and UBSan; exactly reuses original full
BodyPart/BoneId declarations, unchanged GetBodyPartCount and the staged original
entry. A labeled synthetic loader supplies route events; the original MapServer
and original shared/text/allocator branches are not compiled or executed.
Independent Python decoding verifies every field of minimum/maximum payloads.
Tests cover capacity/overflow/alias refusal, partial-read/text fallback, changed
source rows, pointer/count replacement, reload/cancellation, exclusive-file and
write/close/unlink faults, and256 repeated capture/compare/export/wipe cycles.
LeakSanitizer is disabled explicitly. No Android/Home/resume or physical Thor
result follows from these host source-producer tests.
