# Original server initial-response observation

This new wrapper runs one private original Db/Map transaction against the
existing disposable graphical-fixture backup. It observes the original server
initial-send path and the current native receiver's existing receive counters.
It does not alter packet, timeout, READY, ACK, authentication or character policy.
The restored fixture, fresh Wine/PostgreSQL process tree and loopback receiver
are separate from the physical Thor session. Their outcome can identify an
observed boundary in this transaction; it cannot establish the Thor timeout's
cause by itself.

`capture_groups_transaction.py` remains unchanged (SHA256
`35d840f2ca04b320c462cc016f44910c4100e1210e203845df62ffc8de0527a4`).
The wrapper temporarily adapts its fixed Python dispatch hooks inside one call,
then restores every attribute even on exceptions. Two internal dictionary copies
select its existing fresh-observer and initial-progress lifecycle capabilities.
The actual new Map/native receipt bytes, hashes and roles remain authoritative;
the private final report records those actual roles. The copies never assert
equivalence to an older artifact.

The Map receipt is admitted by
`tools/server-initial-observer-20261018/recipe.py::verify_artifact`, including its
exact new-role source closure, staged source reversal, PE, CMake and artifact
inventory. The new native ELF is admitted by C's `receive_admission.py`, including
its current compiler dependency closure, ELF/build proof and reversible baseline
progress body. The supervisor additionally checks PE imports and the staged
runtime's complete dependency closure. It replaces only `MapServer.exe`.

The precreated ledger is the fixed private 0600 single-link regular file
`C:\coh-native-catalog\server-initial-ledger.json`, under the same owned private
directory as the accepted source capture. Only the actual owned Map child gets
`COH_NATIVE_INITIAL_SEND_LEDGER_OUTPUT`. The ledger owner is bound to that
`Popen` and its two registered log streams. A's source producer arms only after
successful same-owner GROUPS commit. After process/stream closure and independent
cleanup, collection validates the exact inode, unchanged bytes, 4096-byte bound,
fixed producer parser and `groups_owner_bound`. It also requires the supervisor's
restored-character membership and exact source/native GROUPS logical-byte pair.
No caller-supplied owner value establishes this binding.

The producer's `ACTIVE`, `FINAL_RETURN` and `REFUSED` are preserved. Terminating
the Map child never changes an ACTIVE snapshot into FINAL_RETURN. VALID on the
outer admission means a bound file was validated; inspect the nested producer
`valid`, `stop`, `refusal`, stage and counters for its actual observation. Empty
producer bytes are UNAVAILABLE; invalid ownership/schema/binding is REFUSED.
ACTIVE is only the last successfully persisted checkpoint; it cannot prove
that later events did not occur or that the sink remained healthy afterward.
`pkt_send_result` records the original call result, including zero; it proves
neither queue acceptance nor a socket send. Even FINAL_RETURN grants no complete
initial-character, application ACK, actor or world authority.

source revision:

```sh
python3 native-android/tools/server-initial-runtime-20261018/runtime.py capture \
  --source-revision "$GITHUB_SHA" \
  --runtime "$CONTROL_RUNTIME" --control-fixture "$CONTROL_FIXTURE" \
  --db-donor-apk "$DB_DONOR_APK" \
  --compile-directory "$NEW_MAP_DIRECTORY" \
  --compile-receipt-sha256 "$NEW_MAP_RECEIPT_SHA256" \
  --database-dump "$EXISTING_PRIVATE_DUMP" \
  --database-dump-sha256 "$EXISTING_PRIVATE_DUMP_SHA256" \
  --account-file "$PRIVATE_ACCOUNT_FILE" --wire-slot 0 \
  --native-capture "$NEW_RECEIVE_ELF" \
  --native-build-receipt "$NEW_RECEIVE_BUILD_RECEIPT" \
  --native-build-receipt-sha256 "$NEW_RECEIVE_BUILD_RECEIPT_SHA256" \
  --pg-bin /usr/lib/postgresql/18/bin \
  --wine /opt/wine-stable/bin/wine --wineserver /opt/wine-stable/bin/wineserver \
  --work "$PRIVATE_WORK" --output "$PRIVATE_RESULT" --timeout-seconds 1200

python3 native-android/tools/server-initial-runtime-20261018/runtime.py project \
  --private-output "$PRIVATE_RESULT" --output out/server-initial-public/observer.json
```
