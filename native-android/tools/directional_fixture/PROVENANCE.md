# Gate21 directional fixture provenance

Eight exact source `.anim` members come from the previously accepted
`coh-assets-v1.0.0` Atlas release. `pins.json` records each original ZIP member
name, byte offset, compressed/uncompressed size, CRC32 and SHA256. The ready,
run and post clips reuse gates16–18 bytes without alteration. Bounded ZIP ranges
acquire Huge runback/run_left/run_right and male walk/skel_ready2. The entire
release ZIP is not downloaded or locally full-hash verified; each selected
member is checked against its pinned hash, size and CRC.

`prepare.py` produces a versioned `COHLOCO2` envelope with12 canonical `COHRIG01`
views. Original encoded key files remain unchanged, including genuine Huge-to-male
parent fallback. Authored ranges and default5/RunPost8 interpolation come from
pinned source sequencer data. `check.py` validates the selected adapter against
unchanged original source kernels with minimal platform/type stubs and source
parsed selected move records. Pinned `source-pins.json` verifies code/data inputs
before oracle execution. The original source files are acquired/cache inputs,
not copied new implementation code in the native client.

The selected fixture omits random Ready2 graphs and non-ground/weapon/combat/FX
or server-authoritative sequencing. Desired-direction flags remain held against
obstacles, with source MoveScale minimum .25; obstacle release follows authored
Pre/Cycle stop graphs. Physical AYN Thor acceptance remains separate from host
source parity.
