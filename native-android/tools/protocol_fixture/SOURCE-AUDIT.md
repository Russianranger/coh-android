# Selected packet source audit

All links below refer to immutable primary source. Full-file and selected
function hashes are enforced by `source-pins.json` and `prepare.py`.

- [UtilitiesLib BitStream.c](https://github.com/Russianranger/coh-android/blob/61bcde64ece0c45a1e3ba1c39f038b15dc6efd7d/upstream/ouroboros/libs/UtilitiesLib/src/components/BitStream.c): `bsWriteBits` and `bsReadBits` consume low-order bits first; `bsWriteBitsPack` and `bsReadBitsPack` implement sentinel/subtraction/doubling, with a terminal 32-bit width. Array writing aligns the cursor to the next byte and copies `ceil(bits/8)` physical bytes while retaining the logical bit count.
- [net_packet.c](https://github.com/Russianranger/coh-android/blob/61bcde64ece0c45a1e3ba1c39f038b15dc6efd7d/upstream/ouroboros/libs/UtilitiesLib/src/network/net_packet.c): original packet helpers dispatch directly to untyped bitstream functions when `hasDebugInfo=0`. Five unchanged dispatch bodies are executed in the host oracle; typed helpers trap because they are outside the selected profile.
- [netio_core.c](https://github.com/Russianranger/coh-android/blob/61bcde64ece0c45a1e3ba1c39f038b15dc6efd7d/upstream/ouroboros/libs/UtilitiesLib/src/network/netio_core.c): unchanged `pktWrap`, `pktSendAcks` with zero ACK count and `blowfishPad` bodies are executed. The full original `pktUnwrap` includes connection state, ACK/retransmission bookkeeping, sibling metadata and optional compression/ordering; that stateful path is not implemented or claimed here. The native decoder is a new checked parser of the selected producer contract.
- [netio_send.c](https://github.com/Russianranger/coh-android/blob/61bcde64ece0c45a1e3ba1c39f038b15dc6efd7d/upstream/ouroboros/libs/UtilitiesLib/src/network/netio_send.c): `pktSendRaw` computes `length=blowfishPad(length)`, writes `cryptAdler32(buf+8,length-8)` at offset 4 and encrypts `buf+4,length-4`. Those field offsets are reproduced; socket and scheduling code are not executed.
- [net_structdefs.h](https://github.com/Russianranger/coh-android/blob/61bcde64ece0c45a1e3ba1c39f038b15dc6efd7d/upstream/ouroboros/libs/UtilitiesLib/include/utilitieslib/network/net_structdefs.h): `PacketHeader` contains two U32 fields, logical bit length and checksum. `COMM_CONNECT=1` agrees with the selected oracle constant; compression/order capabilities are false regardless of payload command.
- [net_packet.h](https://github.com/Russianranger/coh-android/blob/61bcde64ece0c45a1e3ba1c39f038b15dc6efd7d/upstream/ouroboros/libs/UtilitiesLib/include/utilitieslib/network/net_packet.h): `DEFAULT_PACKET_BUFFER_SIZE=1472`, default send-buffer limit 1264, and nondebug miscellaneous allowance 36. Native input has a lower bounded payload policy.
- [crypt.cpp](https://github.com/Russianranger/coh-android/blob/61bcde64ece0c45a1e3ba1c39f038b15dc6efd7d/upstream/ouroboros/libs/UtilitiesLib/src/network/crypt.cpp): unchanged `cryptAdler32` invokes CryptoPP `Update` and `Final`, stores digest bytes in a U32 and swaps only on a big-endian build. Selected host and Android targets are little endian.
- [CryptoPP.cmake](https://github.com/Russianranger/coh-android/blob/61bcde64ece0c45a1e3ba1c39f038b15dc6efd7d/upstream/ouroboros/cmake/dependencies/CryptoPP.cmake) and [exact CryptoPP adler32.cpp](https://github.com/weidai11/cryptopp/blob/b5242667a24e3db8e4600e77b2e502ef204e5280/adler32.cpp): current dependency pin and actual high-to-low digest order. Unchanged `Adler32::Update`/`TruncatedFinal` bodies run in a minimal class shim. `Final` delegates to `TruncatedFinal(...,4)`; class reset/size checking scaffolding is supplied explicitly.

The native module sends no packet, opens no port and grants no Android network
permission. An unchanged-server handshake requires a later separately scoped
connection/lifecycle/authentication gate.
