# Native Integration Probe: gates 13–15

One isolated Android package advances the accepted source diagnostics:
on-device authentic Ogg decoding, real local UDP packet exchange and current
input controlling the authentic Atlas bench camera.

The previous World and Systems probes and production launcher stay separate.
No server setup or asset import is needed. This app ships its small pinned
fixtures and statically built codec. Its network permission supports real UDP
sockets bound exclusively to IPv4 loopback; it has no remote server/login UI.

Read [PHASES13-15.md](../PHASES13-15.md) for source, acceptance and scope, then
use [THOR-TEST.md](THOR-TEST.md) for one device sequence and one exported JSON.
