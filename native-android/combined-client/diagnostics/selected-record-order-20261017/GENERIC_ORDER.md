This additive helper preserves the frozen selected-self outer provider. It
executes the same whole unchanged original initial `sendEntity` control function
with explicit injected child spans. Its five fixture profiles are self-player
with character, another player with character, another NPC with character,
another NPC without character, and another NPC with NetFX but no character.
These are outer predicate profiles; original entity type/appearance construction
and child object graph are not established by profile labels.

`generic_order.build(root, work)` returns a ctypes library and source proof.
The existing clear/set-child API remains available. The new function is
`record_generic_outer(profile, scenario, aligned, prefix, out, &bits, &begin,
eventTriples, &eventCount)`. Buffer capacities remain output65,536bytes,
72eventU32s; child spans at most65,536bits. Profile0..4, scenario0..15,
unaligned prefix0..7 or aligned prefix0 only. Events are exact original child
call start/end cursors; no selected-self thirteen-boundary assumption is applied.
`record_generic_indices(index, previous)` sets fixture-only indices1..10239 and
0..10239 respectively (defaults17/16), preserving original signed-negative
subtraction through the U32 bit writer. It does not establish a real entity-list
index or server owner.

Initial full update forces create/full pose, modes, movement and rare groups.
Original outer source computes character-related grammar from character OR
NetFX presence, while inventory and taskforce groups require pointer-equal self.
Nonself status updates are absent under this source profile. Titles depend on
player storage. Source inline fields remain actual original writes; all child
calls are immutable span adapters. Mission/owned costume and nonself power
choices require independently qualified child payloads supplied by C.

The executable control corpus has720profiles and28,964controls: exact marker
call-order/body/cursor checks,144byte-identical comparisons to the frozen self
provider, and10zero/forward/negative index-delta checks. These marker children
qualify outer ordering only. Helpers, original inputs and included headers are
frozen before imports and checked afterward. Original trusted host writers are
not sanitizer qualified; there is no whole-engine/object-graph, complete
initial-list, dictionary, live-server, actor or ACK admission. Integrating actual
nonself child bodies and native generic parser is a separate qualification.
