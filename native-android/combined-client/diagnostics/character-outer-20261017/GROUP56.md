# Complete original outer tail oracle

`group56_oracle.py` adds exact original sender and receiver statement blocks from
reward-token count through rename. It executes full unchanged original chat,
keybind, friends, title/description/divider, options and combat-monitor helpers.
It does not execute the preceding original `character_Receive` gameplay function.

The 100 synthetic cases cover both scalar alignment profiles, bit offsets0–7
or byte offsets0/8, saved/default options, profile fallback, empty/nonempty tokens,
online/offline friends, optional monitor values, titles and rename. Every original
producer/consumer end cursor agrees. A separate bounded Python decoder compares
every projected field: both token lists; all chat windows/tabs/channels and system
words; titles/text;256keybinds;114saved options or3mouse defaults; dividers and
control words; friends and class/origin sentinels;10monitor pairs and rename.

`generate(texts)` returns C source, function hashes and exact block hashes.
`qualify(texts)` compiles and returns cases with raw bytes and an explicit
`expected` dictionary. Source text is read from immutable original pin767d55e48;
all original bytes must match `group56-source-pins.json`, including the whole
original automatic-bit producer/consumer functions.

Generated C exports `group56_fixture(scenario,aligned,prefix,out,bits,end,observed)`.
Byte output capacity is1MiB; observed capacity is31unsigned32words. After that
call, `group56_observe(words,text,word_count,text_bytes)` emits the explicit
original-consumer projection (8192unsigned32word and131072byte capacities).
`projection(words,text)` converts those pools into the named expected dictionary.
Wire key profile and original development-mode application profile are separate.
The raw native parser should compare wire data; it must not apply commands/UI.

Fixture dictionaries, earray/token storage, profile/runtime context and UI
callbacks are explicit shells. Chat fixtures use already migrated/localized
settings; default/migration/localization callback semantics are not qualified.
They do not send packets into the current body. Source globals and field layouts
are fixture shells, not original ABI claims. Actual unknown dictionaries, prior
state and production UI remain unqualified. Original x86 bit routines execute
unsanitized; native parsers consume generated bytes under separate sanitizers.
No malformed body is executed by these original routines.

Reproduce:

```sh
python3 native-android/combined-client/diagnostics/character-outer-20261017/group56_oracle.py --output /tmp/new-group56-proof.json
python3 -m unittest discover -s native-android/combined-client/diagnostics/character-outer-20261017 -p 'test_group56.py' -v
```

Six tests pass: all fields, final-bit truncations, changed chat-field refusal,
missing source-pin refusal, both option/profile branches and explicit incomplete
character scope. Earlier seven group4/helper tests remain unchanged. Native
complete outer-character composition, dictionaries, enclosing update transaction,
Android, physical device and actor/ACK qualification are distinct later gates.
