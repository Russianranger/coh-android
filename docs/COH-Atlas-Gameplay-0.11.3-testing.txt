COH Atlas Gameplay 0.11.3 — bounded play and normal-save window

Install this APK as an update. Keep app data, imported assets and saved THORHERO.
Tap Refresh runtime once, then Reopen saved THORHERO. Log in COHLOCAL / offline.
If the initial map load returns you to login, wait and enter the existing character
again. This update retains the current native loading/network behavior.

The login window remains 20 minutes. A verified native character connection gets
its own allowance, bounded by the existing launcher lifetime. After ordinary
Return to safe ground, the actual delivered /stuck command anchors these limits:
movement ends at 6 minutes, Save cutoff at 7 minutes, and save proof/Finish at
10 minutes. The launcher and overall-operation caps can shorten these windows.
Follow the app's separate movement, Save and proof countdowns.
