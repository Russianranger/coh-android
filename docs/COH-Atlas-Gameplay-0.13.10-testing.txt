This asset-focused release adds exact original files selected from the 0.13.9
report, stock costumes, all original Atlas world model/material tables and
their blend, mask, bump, glow and enabled fallback dependencies. It includes
heads, hand/glove geometry, NPC textures, ground/bench materials and observed
missing effect/weapon geometry. Every previous visual leaf is preserved.
Native Game, DLLs, DEX/Java, server binaries, startup behavior, cache formats,
graphics and animation tracks are retained. No complete-global-coverage claim
is made: several diagnostic categories were capped and original alias gaps
remain. Appearance still requires the Thor test.

The expansion adds 5,147 original leaves (412 GEOs and 4,735 textures), about
795 MiB of decoded files. It is substantially larger than prior updates.
Installation writes missing files to private storage with bounded per-file
streaming; it does not preload all new textures/models into RAM. Only the named
visual input limits and exact server staging budgets increase for this pack. The first
visual installation and texture-header refresh take extra preparation time.
Record that separately from actual Game launch-to-login. Existing caches and
runtime reuse remain available. Startup optimization is the following step.

The 0.13.9 report rejected earned XP/influence after combat. This update allows
only changes exactly explained by the owned native reward logs, retaining all
other selected character rows, ordinary logout and saved-position checks. It
does not grant rewards or change the native server. The old raw report remains
failed; host tests/replay qualify the correction, not a new physical save pass.
